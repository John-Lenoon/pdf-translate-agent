# Requirements

## Product goal

在本地将数字文本型英文现代小说 PDF 翻译为中文，优先保证上下文连贯性、忠实度和页面结构保真。

## V1 scope

- 输入：数字文本型 PDF；不支持 OCR 扫描件。
- 内容：现代小说；英文到中文。
- 容量：首先验证 10 页以内闭环，初步支持 50 页以内；不设置 SLA。
- 输出：独立的中文阅读版 PDF。保留原 PDF 文件不变。
- 结构：保留章节、段落、图片和地图；保持原纸张尺寸，但中文可自然增加页数。正文不得为塞入原页而缩小字号。
- Entity：自动管理全书全局唯一的人物名。
- Glossary：只使用用户预先提供的 Glossary；模型建议翻译完成后查看，不阻塞流程。
- Review：翻译完成后提供本地网页进行人工 Judge 抽样和段落级重译。
- Deployment：仅本地运行，不做公网部署或多租户。

## User-visible success criteria

- 用户无需逐段确认即可完成首次翻译。
- 人物标准译名在整次运行中不漂移；同一 `source_name` 不允许产生两个 canonical `target_name`。
- 译文不得静默漏段、截断或产生缺字；任何异常必须显示在运行报告中。
- 人工 Judge 能从页面或段落定位问题，记录标签和备注，并只重译被标记段落。

## Non-goals

V1 不实现 OCR、PostgreSQL、向量数据库、自动术语学习、多模型路由、协作权限、在线 SaaS、完整 PDF 阅读器或自动排版完美还原。多模型路由已纳入 V2；其余能力仍须通过后续版本目标和 ADR 明确后才能实施。

## V1 acceptance

1. 对测试 PDF 完成解析、分段、翻译、Entity 记录、覆盖渲染和结果读取。
2. 翻译流程不要求用户逐段确认即可完成。
3. 人物名在后续命中时复用已记录的标准译名。
4. Judge 可标记单个段落并触发局部重译。
5. 原文 PDF 未被修改；译文 PDF 的章节、中文字号、图片/地图、页码和输出文本完整性可验证。
6. 任务中断后可从已完成段落恢复，不重复覆盖有效结果。
7. 关键 Prompt、模型、AST 和 Workflow 版本可追溯。
8. Golden Set 至少包含 30 个段落，覆盖叙事、对白、人物首次出现、跨页段落和页眉页脚；每次版本运行都保存人工 Judge 结果。
9. 任一测试 PDF 出现文字截断、缺字或不可读取页面时，运行不得标记为 `completed`。
